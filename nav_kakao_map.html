캠퍼스 길찾기

동아대학교 승학캠퍼스 도로망에서 두 지점 사이의 최단 경로(거리 기준)를 계산하고 카카오맵 위에 표시합니다.

지도가 표시되지 않는다면 이 파일 하단의 KAKAO_APP_KEY 값이 YOUR_KAKAO_APP_KEY 그대로인지 확인하세요. 카카오 디벨로퍼스(developers.kakao.com) → 내 애플리케이션 → 앱 설정 → 플랫폼에서 JavaScript 키를 발급받고, Web 플랫폼 도메인에 지금 접속 중인 주소(예: http://localhost:8080)를 정확히 등록해야 지도가 로드됩니다.
